## Code with a long line

```text

This deliberately long code line should scroll horizontally inside its own block without making the entire document wider than the window: alpha beta gamma delta epsilon zeta eta theta iota kappa lambda mu nu xi omicron pi rho sigma tau upsilon phi chi psi omega.
```

The prose below the code should wrap normally. Keyboard users can Tab between the document, table, code block, and link. Inside an embedded block, copying selects its own text; selecting across a block in the main document copies the entire block.
